# MEMORY.md — Persistent State Management

## Memory Layers
1. **Rolling Memory (Active):** Tracks the current segment, visual state, and time since last cut.
2. **Session Memory (6-hour):** Stores the `visual_log`, `graphics_aired`, and audience engagement profiles for the current stream.
3. **Persistent Memory (Long-term):** Tracks recurring viewers, running editorial positions, and network milestones across restarts.

## TV-Specific Continuity
- **Visual Memory:** The Director remembers the sequence of scenes to avoid repetitive cutting patterns.
- **Narrative Loops:** The Producer tracks multi-day story arcs, allowing anchors to reference past coverage accurately.
- **Audience Recognition:** The Community Manager identifies VIP viewers across different stream sessions.
